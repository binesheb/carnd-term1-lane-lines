# Changelog

All notable maintenance changes to this repository are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) principles and this repository uses [Semantic Versioning](https://semver.org/).

## [0.1.2] - 2026-08-21

### Changed

- Clarified that the archived notebooks should use current, supported Python packages instead of reviving the original 2017 dependency stack.
- Added an explicit policy against reintroducing deprecated or unmaintained packages solely for historical reproducibility.

## [0.1.1] - 2026-08-20

### Changed

- Replaced the minimal top-level README with a repository-level overview and an accurate description of the preserved notebook collection.
- Added a modern Python/Jupyter setup path instead of relying exclusively on the historical 2017 Udacity starter environment.
- Documented safe manual update commands, reproducible tag/commit pinning, and the policy for future releases.
- Clarified that the project is maintained as an archived learning repository rather than silently presenting the coursework as a current production application.
